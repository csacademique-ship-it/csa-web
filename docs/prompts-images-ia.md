# Les 18 visuels du site — prompts prêts à coller

Le site attend une image par formation. Tant qu'une image manque, un bloc
bleu aux couleurs CSA prend sa place — le site n'est jamais cassé, mais il
paraît inachevé. Ce document contient les 18 prompts à utiliser.

---

## Mode d'emploi en 4 étapes

1. **Ouvrez un générateur d'images** — ChatGPT (GPT Image), Gemini, Midjourney,
   Leonardo, Ideogram. N'importe lequel fait l'affaire.
2. **Collez le bloc « STYLE COMMUN » ci-dessous, puis le prompt de la formation.**
   Le style commun est ce qui donne aux 18 images l'air d'appartenir au même
   site. Ne le sautez pas.
3. **Demandez le format 16:9** (paysage large). Si l'outil propose une taille,
   visez 1600 × 900 pixels ou plus.
4. **Enregistrez le fichier** dans `public/images/formations/` sous le nom
   exact indiqué, puis lancez `npm run build`.

> **Formats acceptés**, par ordre de préférence : `.webp`, `.avif`, `.jpg`,
> `.png`. Le WebP pèse deux à trois fois moins lourd qu'un JPEG à qualité
> égale — c'est ce qu'il faut privilégier pour des visiteurs en 3G.

---

## STYLE COMMUN — à coller AVANT chaque prompt

```
Photographie et rendu 3D hybride, style éditorial technique haut de gamme.
Format 16:9 paysage, 1600x900.
Palette stricte : bleu profond #0D5F99, bleu vif #2B91D4, bleu clair #5BAEE0,
bleu très pâle #D6ECFA, blanc, gris anthracite. Aucune autre couleur dominante.
Éclairage doux et directionnel, ambiance sérieuse et professionnelle.
Composition épurée, beaucoup d'espace négatif, sujet décentré.
AUCUN texte, AUCUN chiffre, AUCUN logo, AUCune interface de logiciel lisible,
AUCUN visage reconnaissable.
Rendu net, réaliste, qualité magazine scientifique. Pas de style cartoon,
pas d'illustration plate, pas de dégradé arc-en-ciel, pas de néon.
```

## Les 18 prompts

### 1. `geostatistique-r-python.webp`
**Data Analyse & Géostatistique — R et Python**

```
Un bloc de carottes de forage minier disposé en diagonale sur un plan de
travail sombre, avec en surimpression translucide des courbes statistiques
et des nuages de points bleus flottant au-dessus, comme un hologramme discret.
Profondeur de champ marquée sur les carottes.
```

### 2. `acp-rstudio.webp`
**ACP en géosciences avec RStudio**

```
Un nuage de points tridimensionnel bleu suspendu dans le noir, formant deux
groupes distincts séparés par un espace vide, traversé par trois axes fins
lumineux. Rendu volumétrique, particules de tailles variées, effet de
profondeur. Abstraction scientifique élégante.
```

### 3. `sql-bases-geologiques.webp`
**SQL pour bases de données géologiques**

```
Des blocs de données translucides bleus empilés et reliés par des filaments
lumineux, formant une architecture ordonnée sur fond sombre. Vue en légère
plongée. Sensation de structure, de rigueur et de connexion.
```

### 4. `isatis-neo.webp`
**ISATIS NEO — exploration minière**

```
Un modèle de blocs minier tridimensionnel vu en perspective isométrique,
cubes bleus de teintes variées formant un gisement enfoui, traversé
verticalement par de fines lignes claires représentant des sondages.
Fond dégradé bleu profond.
```

### 5. `isatis-pollution.webp`
**ISATIS — cartographie de la pollution**

```
Vue aérienne d'un terrain industriel abandonné, avec un panache diffus
translucide bleu s'étendant depuis une source vers une rivière. Contours
concentriques subtils autour de la source. Atmosphère matinale, brume légère.
Sobriété documentaire, aucune dramatisation.
```

### 6. `sig-teledetection-pollution.webp`
**Cartographie pollution — SIG et télédétection**

```
Image satellitaire stylisée d'un bassin versant africain vue depuis l'orbite,
méandres d'une rivière, mosaïque de parcelles, le tout traité en camaïeu de
bleus. Un cadre fin délimite une zone d'étude. Netteté d'image satellite
haute résolution.
```

### 7. `google-earth-engine.webp`

**Aéromagnétisme sous Oasis Montaj**

**QGIS Pro**

```
Plusieurs couches cartographiques translucides empilées en perspective, comme
```

**IA générative appliquée**

## Après la génération

```bash
# 1. Déposez les fichiers dans public/images/formations/
# 2. Reconstruisez
npm run build
```

Le build liste les images encore manquantes à chaque exécution :

```
  !!  3 visuel(s) manquant(s) sur 18 -> bloc de remplacement affiche.
        Deposez les images dans public/images/formations/ :
        - datamine-rm.webp
        - ...
```

Quand la ligne devient `OK 18 visuels presents`, tout est en place.

### Alléger les images avant de les mettre en ligne

Une image générée pèse souvent 2 à 4 Mo — beaucoup trop pour un visiteur en
3G à Ouagadougou. Passez-les par un compresseur avant de les déposer :

- **squoosh.app** — gratuit, dans le navigateur, rien à installer.
  Réglez : largeur 1600 px, format WebP, qualité 75.
- Visez **moins de 200 Ko par image**. Le site entier doit rester sous 5 Mo.

## Si vous préférez de vraies photos

Une photo réelle d'une session CSA, ou une capture d'écran d'un logiciel
pendant une démonstration, vaut mieux qu'une image générée — surtout pour une
formation technique, où le prospect cherche à se projeter.

Le système est identique : nommez le fichier avec l'identifiant de la
formation et déposez-le au même endroit. Deux règles :

- **Accord des personnes photographiées** avant toute publication.
- **Aucun nom d'apprenant visible** sur une capture d'écran ou un document
  filmé — c'est la règle de confidentialité CSA.
